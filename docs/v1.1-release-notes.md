## Enabling automatic scoring (optional — pg_cron)

By default, `score_reports()` runs opportunistically after each check-in, which
is plenty at launch. To have it run on a fixed timer regardless of activity:

1. Supabase → **Database → Extensions** → enable **pg_cron** (and **pg_net** is
   not needed here).
2. Supabase → **SQL Editor**, run:

```sql
select cron.schedule(
  'score-reports',
  '*/5 * * * *',                 -- every 5 minutes
  $$ select public.score_reports() $$
);
```

To change the cadence later, unschedule then reschedule:

```sql
select cron.unschedule('score-reports');
```

Check it's registered:

```sql
select jobid, schedule, command from cron.job where jobname = 'score-reports';
```

> Not required for launch. Opportunistic scoring already resolves reports a few
> minutes after they're submitted, which is when peers exist to compare against.
